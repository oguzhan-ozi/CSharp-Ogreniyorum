# 🚀 C# İnteraktif Öğrenme Platformu - Gelişim ve Fark Yaratma Planı (Progress)

Bu belge, platformu sıradan bir kodlama eğitim sitesinden çıkarıp, piyasada **rakipsiz** bir "Yazılımcı Fabrikasına" dönüştürmek için uygulanacak yenilikçi vizyon maddelerini ve mevcut ilerleme durumumuzu takip etmektedir.

---

## 1. 🏗️ Çekirdek Yapı ve Müfredat (Tamamlananlar)
Platformun temel iskeleti ve eğitim müfredatı başarıyla kurulmuştur.
- [x] **Modern UI/UX:** Karanlık tema, Glassmorphism tasarımı, Sidebar navigasyonu.
- [x] **İnteraktif IDE Entegrasyonu:** Monaco Editor kullanılarak tarayıcı içi C# simülasyonu.
- [x] **Gelişmiş Quiz Motoru:** Doğrusal olmayan, anlık geri bildirimli çoktan seçmeli testler.
- [x] **Profil ve İlerleme Sistemi:** Kullanıcı deneyimini (XP), tamamlanan dersleri izleme.
- [x] **Bağımsız Veri Yönetimi:** Backend olmadan (Import/Export .json) kullanıcı verisi taşıyabilme.
- [x] **Kapsamlı W3Schools Müfredatı:** Temel syntax, döngüler ve OOP prensipleri.
- [x] **Niş/İleri Seviye Modüller:** LINQ, Generics (&lt;T&gt;), Asenkron (async/await) programlama gibi derinlemesine içerikler üretildi. (Madde 5'in ilk adımı atıldı).

---

## 2. 🌍 Local Environment ve Deployment Simülasyonu
Kullanıcıya sadece kod yazdırmak yerine, gerçek dünya senaryolarını yaşatan modüller eklenecektir.
- [x] **Sanal Veritabanı Bağlantısı:** Derslerde sahte bir veritabanı bağlantı dizesi (Connection String) ile veri çekme (CRUD) simülasyonu.
- [x] **Deployment (Dağıtım) Rehberi:** Yazılan bir C# Console veya Web API uygulamasının sunucuya nasıl yükleneceğini anlatan interaktif senaryolar.
- [x] **Dosya Sistemi (File I/O) Modülleri:** `File.ReadAllText` gibi metotlar için sanal bir dosya sistemi simülasyonu oluşturma.

---

## 3. 🐛 "Debug Modu" Görevleri (Hata Çözme Odaklı Eğitim)
Sıfırdan kod yazdırmanın yanı sıra, gerçek yazılımcılık olan "hata çözme (debugging)" kasını geliştirecek özel seviyeler tasarlanacaktır.
- [x] **Hatalı Kod Senaryoları:** İçerisinde kasti yapılmış 3 kritik syntax veya mantık hatası bulunan kod bloklarının hazırlanması.
- [x] **Hata Logu Simülasyonu:** Kullanıcı kodu çalıştırdığında gerçekçi derleyici (compiler) hataları fırlatarak kullanıcının hatayı bulmasını sağlayan mekanizma.
- [x] **Debug İpuçları:** "IndexOutOfRangeException" gibi sık karşılaşılan hataların ne anlama geldiğini öğreten mini pop-up'lar (teori dersleri).

---

## 4. 🤖 AI "Pair Programmer" (Eşli Programcı) Entegrasyonu
Kullanıcı tıkandığında doğrudan cevabı vermek yerine Sokratik yöntemle düşündüren bir asistan.
- [x] **Sokratik Asistan Paneli:** IDE içinde açılıp kapanabilen, ipuçlarını adım adım gösteren özel Pair Programmer paneli ve butonu eklendi.
- [x] **Bağlam (Context) Farkındalığı:** Editördeki kod değişimini izleyip ipuçlarını otomatik yenileyen (yeniden analiz) gerçek zamanlı bağlam farkındalığı aktif edildi.
- [x] **Cevap Değil Yönlendirme:** Doğrudan çözüm vermek yerine düşündüren, ders odaklı Sokratik ipucu akışı ve yönlendirici diyalog tasarımı tamamlandı.

---

## 5. 🏆 "Capstone" Projeleri ve GitHub Entegrasyonu
Eğitim bittiğinde kullanıcının elinde gerçek ve çalışır bir ürün kalmasını sağlamak.
- [x] **Bölüm Sonu (Boss) Projeleri:** Capstone Merkezi eklendi; Konsol tabanlı Banka Otomasyonu ve Todo List projeleri, teslim kriterleri ve proje akışıyla entegre edildi.
- [x] **Tek Tuşla GitHub Export:** Capstone ekranına GitHub Export butonu eklendi; proje kodu + README tek tıkla export edilip GitHub yeni repo sayfasına yönlendirme akışı hazırlandı.
- [x] **Portfolyo Linki:** Proje tamamlanınca paylaşılabilir dinamik portfolyo linki (#cert=...) oluşturuluyor.
